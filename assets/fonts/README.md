# Lettertype

`Baloo2.ttf` — Baloo 2, ontworpen door Ek Type.
Bron: https://fonts.google.com/specimen/Baloo+2

Gelicentieerd onder de SIL Open Font License 1.1 (`OFL.txt`). Die licentie staat
gebruik in commerciële video's toe, ook zonder naamsvermelding.

Een ander lettertype gebruiken? Zet het hier neer en pas de naam aan in
`src/ytauto/render/scene.py` (`load_font`, parameter `family`). Ontbreekt het
bestand, dan valt de renderer terug op een systeemlettertype.
